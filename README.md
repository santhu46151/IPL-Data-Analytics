# 🏏 IPL Data Analytics — Excel Project

An end-to-end data analytics project exploring Indian Premier League (IPL) match and player data using **Microsoft Excel**. The project transforms raw IPL datasets into a clean, interactive dashboard with actionable insights on team performance, player stats, and match trends.

---

## 📌 Project Overview

This project analyzes historical IPL data to uncover patterns in team performance, top-performing players, venue trends, and season-wise outcomes. It demonstrates core data analytics skills — data cleaning, transformation, DAX-style calculations (via Excel formulas/Pivot Tables), and dashboard design — using only Excel.

---

## 🎯 Objectives

- Clean and structure raw IPL data for analysis
- Identify top-performing teams and players across seasons
- Analyze toss decisions, win margins, and venue-based trends
- Build an interactive, visually appealing Excel dashboard
- Present insights in a portfolio-ready format for recruiters
